# 评测用例

- 放置 JSON/JSONL 用例、小型张量样例、固定 token 输入及数据集清单。
- 按 `correctness/`、`performance/`、`agent/` 等用途在需要时继续细分。
- 开发、回归、保留用例应有明确标识和版本，避免混用。

`task-quality-core.json` 包含 10 条人工指定答案的基础任务，由受信任的 `scripts/evaluation/quality_cases.py` 评分；答案不从初始引擎输出生成。本地及 Qwen 27B 默认配置重复执行 3 次，以最差准确率检查 0.8 的下限及相对初始最差分数 0.05 的退化上限。

该公开小集用于发现基本语义错误，不是业务基准或保留集，阈值尚未在目标 Qwen 上校准。真实活动应增加独立确认的领域题、边界题与保留集，并在活动开始前冻结评分脚本、数据和阈值；修改后需要新活动。
